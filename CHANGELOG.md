# Changelog

All notable changes to Milo will be documented in this file.

## [Unreleased]

### Added

- Initial version of Milo.
- Multiple IMAP/SMTP accounts, a unified inbox, threaded conversations, and local and server search.
- Rich-text and plain-text composition, detached composer windows, drafts, signatures, attachments, and `mailto:` support.
- Password and OAuth 2.0 authentication, OpenPGP and S/MIME, and remote image blocking by default.
- Experimental Contacts and Calendar extensions.
- Light, Dark, and System appearance, keyboard shortcuts, and English and Russian interfaces.
